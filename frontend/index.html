Core Operational Concept

PowerTrack operates as a digital electricity command center simulating the regional distribution network in Tamil Nadu (Erode, Perundurai, Chennimalai, Tiruppur, Avinashi).

When faults occur, the graph connectivity engine calculates downstream electrical isolation, updates dependent consumer meters, pushes alerts to the Priority Queue (Heap), and tracks field technician dispatch through resolution.

Java Data Structure Mapping

Graph (Adjacency List): Models 230kV/110kV Substations → Feeders → Transformers → Areas.
Queue (FIFO): Sequential ingest of new telemetry alerts.
Priority Queue (Heap): Automated dispatch ordering based on consumer impact & hospital criticality.
Entity Arrays: Fixed-capacity entity stores for high-speed indexing.
